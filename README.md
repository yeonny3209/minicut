# MiniCut

브라우저에서 바로 쓰는 영상 편집기. `index.html` 하나가 전부입니다.
설치도, 빌드도, 서버도, 외부 라이브러리도 없습니다.

영상 파일은 `URL.createObjectURL`로만 읽고 **네트워크로 전송하지 않습니다.**
코드에 `fetch`나 `XMLHttpRequest`가 없어서 네트워크를 끊고 써도 똑같이 동작합니다.

**[편집기 열기](https://yeonny3209.github.io/minicut/)** · **[기능 설명서](https://yeonny3209.github.io/minicut/guide.html)**

## 기능

### 컷 편집
여러 영상 이어붙이기, 재생헤드 분할, 트림, 순서 변경, 복제, 삭제, 속도 0.25~4배.
타임라인 자석(클립 경계·재생헤드·다른 막대에 스냅).

### 전환 효과
클립 사이의 배지를 눌러 **디졸브 · 암전 · 화이트 · 상하좌우 밀기 · 와이프 · 원형 · 줌** 중에서 고릅니다.
길이 0.1~2초. 전환은 뒤 클립의 앞부분에서 일어나므로 전체 길이가 변하지 않습니다.

### 화면 비율과 배경
**16:9 · 9:16 · 1:1 · 4:5 · 4:3.** 가로 영상을 세로 쇼츠로 두 번의 클릭에 바꿉니다.
남는 여백은 흐림 배경 · 검정 · 흰색 · 지정 색 중에서 채웁니다.
클립마다 전체 보기 / 꽉 채우기를 고르고, 확대 · 위치 · 회전 · 좌우/상하 반전을 줍니다.
**미리보기 화면을 끌어** 영상 위치를 직접 잡을 수 있습니다.

### 자막
**미리보기 화면에서 마우스로 끌어** 위치를 정합니다(중앙 스냅 가이드 포함).
스타일 프리셋 10종(기본·박스·네온·만화·레트로·시네마·타자기·손글씨·민트·타이틀),
글꼴 6종, 그라데이션 글자색, 외곽선, 그림자, 네온 글로우, 배경 박스, 자간.
등장 애니메이션 7종(페이드·팝·슬라이드 업·타자기·통통·물결).
SRT 가져오기/내보내기, 긴 자막 문장별 자동 분할.

### 필터 12종
비비드 · 소프트 · 웜 · 쿨 · 느와르 · 빈티지 · 시네마 · 페이드 · 팝 · 선셋 · 민트 · 모노.
구간에만 걸거나 영상 전체에 한 번에 겁니다.

### 효과 14종
페이드 인/아웃, 플래시, 블러, 켄번즈 줌, 줌 펄스, 흔들림, 회전, 글리치, 모자이크, 거울,
흑백, 세피아, 색 반전. 모두 **타임라인의 원하는 구간에만** 들어가고, 겹쳐도 됩니다.

### 소리
배경음악(볼륨 · 페이드 인/아웃 · 시작 오프셋 · 여러 곡), 클립별 볼륨과 음소거.

### 스티커
PNG · JPG · GIF를 얹습니다. 끌어서 위치, 크기 · 회전 · 불투명도 조절. 로고/워터마크용.

### 그 밖에
전역 색보정(밝기 · 대비 · 채도 · 색온도 · 비네트), 구도 가이드(삼분할 · 안전영역),
프로젝트 저장/열기(JSON + 원본 파일 재연결), 실행취소 60단계.

### 내보내기
화면비에 맞춘 720p / 1080p, WebM (VP9 + Opus).

| 화면비 | 720p | 1080p |
|---|---|---|
| 16:9 | 1280 × 720 | 1920 × 1080 |
| 9:16 | 720 × 1280 | 1080 × 1920 |
| 1:1 | 720 × 720 | 1080 × 1080 |
| 4:5 | 720 × 900 | 1080 × 1350 |
| 4:3 | 960 × 720 | 1440 × 1080 |

### 단축키

| 키 | 동작 | 키 | 동작 |
|---|---|---|---|
| `Space` | 재생 / 정지 | `←` `→` | 1프레임 이동 |
| `S` | 재생헤드에서 분할 | `Shift` + `←` `→` | 1초 이동 |
| `T` | 자막 추가 | `Ctrl` + `D` | 복제 |
| `Delete` | 선택 항목 삭제 | `Ctrl` + `S` | 프로젝트 저장 |
| `Ctrl` + `Z` | 실행취소 | `Ctrl` + `Shift` + `Z` | 다시실행 |

`Ctrl` + 휠로 타임라인을 확대·축소합니다.

## 설계 메모

**렌더링은 캔버스 한 장.** `<video>`를 숨겨 두고 매 프레임 캔버스에 그리면서 `ctx.filter`로
색보정과 필터를, 그 위에 효과 · 스티커 · 자막을 겹칩니다. 프리뷰와 내보내기가 `renderFrame()`
**하나만** 호출하므로 "보이는 대로 나온다"가 보장됩니다.

**효과는 클립이 아니라 전역 시간에 붙습니다.** `effects: [{ type, start, end, ...params }]` 이고
각 효과는 자기 구간의 진행도 `p`(0~1)를 받아 동작합니다. 효과를 클립 소속으로 만들면 컷을 다시
나누거나 순서를 바꿀 때마다 "이 장면에서만"이 어긋나는데, 자막과 같은 방식으로 시간에 붙여서
그 문제를 피했습니다.

**모든 좌표와 크기는 해상도와 무관합니다.** 자막·스티커 위치는 화면 비율(0~1)로, 글자 크기·그림자·
블러 반경은 **짧은 변 1080px** 기준으로 환산합니다. 그래서 가로든 세로든, 프리뷰든 1080p
내보내기든 같은 그림이 나옵니다.

**재생 중에는 video가 기준 시계.** 재생헤드를 벽시계(rAF의 경과시간)로 굴리면 디코드 지연이나
탭 스로틀링 때문에 반드시 영상과 어긋나고, 그걸 매 프레임 시킹으로 메우다 보면 `readyState`가
떨어져 화면이 검게 깜빡입니다. 그래서 `video.currentTime`을 기준으로 삼고 재생헤드를 거기에
맞춥니다. 배경음악은 반대로 재생헤드를 따라갑니다.

**오디오는 Web Audio로 한 번 합칩니다.** 내보내는 중에 클립이 바뀌어도 MediaRecorder에 물린
오디오 트랙은 교체할 수 없어서, 모든 미디어를 하나의 믹스 노드로 모아 고정된 트랙 하나를 만듭니다.
소스마다 gain을 두어 클립 볼륨과 음악 페이드를 이 그래프 안에서 처리합니다.

**상태는 순수 JSON 하나.**
`{canvas, clips, effects, overlays, subtitles, audio, adjustments, guides}`.
실행취소는 이 객체의 스냅샷 스택(최대 60개)으로 끝나고, 프로젝트 저장도 같은 구조를 그대로 씁니다.

## 제약

- **내보내기는 영상 길이만큼 실시간으로 걸립니다.** 화면을 `MediaRecorder`로 캡처하는 방식의
  구조적 한계입니다. 진행 중에 창을 가리면 캔버스가 갱신되지 않으므로, 깨진 파일을 내놓는 대신
  중단하고 알려 줍니다.
- **내보내기는 Chrome / Edge 전용입니다.** Safari는 MediaRecorder의 WebM 출력을 지원하지 않습니다.
  편집과 프리뷰는 동작합니다.
- **전환 중 앞 클립은 정지 화면입니다.** 브라우저에서 같은 영상 파일의 두 지점을 동시에 재생할 수
  없어서, 앞 클립의 마지막 프레임을 고정한 채 섞습니다. 0.5초 안팎의 짧은 전환에서는 거의 티가
  나지 않습니다.
- **결과물 WebM을 다시 불러오면 중간 지점 탐색이 깨집니다.** MediaRecorder가 만든 WebM은 seek
  인덱스(Cues)가 없고 키프레임이 드물어서, 중간으로 seek하면 `currentTime`은 정상 보고되지만
  디코드된 프레임은 초반 키프레임에 머뭅니다. 일반 카메라·편집기 mp4는 문제없습니다.
  재편집이 필요하면 프로젝트 파일(JSON)을 저장해 두고 그걸 여세요.
- **자막 글꼴은 이 기기에 설치된 글꼴을 씁니다.** 웹폰트를 내려받지 않으므로(네트워크 무전송 원칙)
  기기마다 모양이 다를 수 있습니다.
- 멀티 비디오 트랙(PIP), 자동 음성인식 자막, 키프레임 애니메이션, 크로마키는 범위에 넣지 않았습니다.
